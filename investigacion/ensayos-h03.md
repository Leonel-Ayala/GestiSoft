# Protocolo de Ensayos de Tiempo de Apertura y Cierre de Caja (H-03)

- **Hipótesis H-03:** *El proceso de apertura y cierre ciego de caja es lo suficientemente ágil y ergonómico como para realizarse en menos de 60 segundos por operación en el mostrador.*
- **Responsable de la medición:** Luis Barrios (UI/UX) y Alan Troncoso (QA Lead).
- **Procedimiento:**
  1. Con el navegador Chrome en `/pos`, el operador presiona `F2` para desplegar el modal de apertura, teclea el fondo inicial ($50.000) y pulsa `Enter`. Se cronometra desde que presiona `F2` hasta que el banner de caja abierta se confirma.
  2. Con ventas procesadas, el operador presiona `F9` para abrir el modal de cierre, digita el efectivo contado y confirma con `Enter`. Se cronometra desde que presiona `F9` hasta que se visualiza el acta de cierre.
